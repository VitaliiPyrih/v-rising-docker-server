# V Rising — Адмін команди

## Авторизація
| Команда | Опис |
|---------|------|
| `adminauth` | Увійти як адмін (вводити першим) |
| `admindeauth` | Вийти з режиму адміна |

---

## Гравці
| Команда | Опис |
|---------|------|
| `listusers` | Список гравців зі Steam ID |
| `kick [нік]` | Кікнути гравця |
| `bancharacter [нік]` | Забанити за ніком |
| `banuser [steamid]` | Забанити за Steam ID |
| `banned` | Список забанених |
| `unban [індекс]` | Розбанити гравця |
| `setadminlevel [нік] [рівень]` | Видати права (Admin / Moderator / None / SuperAdmin) |

---

## Телепорт
| Команда | Опис |
|---------|------|
| `teleport self cursor` | Телепорт до курсору |
| `teleporttomapmarker` | Установіть маркер на карті, після введіть команду. Телепортує на сам маркер.
| `TeleportToPlayer [нік]` | Телепорт до гравця |
| `TeleportPlayerToMe [нік]` | Притягнути гравця до себе |
| `TeleportPlayerToMousePosition [нік]` | Телепорт гравця до курсору |
|

---

## Спостереження
| Команда | Опис |
|---------|------|
| `toggleobserve 0` | Вимкнути режим спостереження |
| `toggleobserve 1` | Невидимий і невразливий |
| `toggleobserve 2` | Видимий привид |

---

## Інше
| Команда | Опис |
|---------|------|
| `addtime [1-12]` | Додати години ігрового часу |
| `changehealthofclosesttomouse [число]` | Відновити/нанести HP (мінус для урону) |
| `give [предмет] [кількість]` | Видати предмет |
| `giveset [назва сету]` | Видати сет предметів |
